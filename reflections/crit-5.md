# Crit 5 reflection

**What was the breakthrough that moved the work forward?**

The breakthrough was realising that "no instructions" did not mean the player should have to guess what to do. Instead of explaining the mechanic with text, I used the interface itself to communicate the action: a bouncing Space-key icon on the opening screen shows the exact input the player needs, flashes when the real key is pressed, and reappears after a win or loss. This made the game more immediately understandable while keeping the screen free of tutorial text. It also gave the interaction a consistent visual language, because the same element communicates both how to start and how to play again.

**What did this work change about who I want to be as a software developer?**

This work made me think more carefully about accessibility as part of interaction design rather than something added at the end. I learned that users should not need to read instructions or already understand the game to know what action is expected. Clear visual feedback can make an interface more approachable while still keeping the experience simple. I want to become a developer who considers how different users will discover and understand an interaction from the beginning, and who uses design, feedback, and testing to reduce unnecessary barriers rather than relying on instructions to explain confusing behaviour.
